## 系统概述

`combined_robot_control.py` 是一个集成了FR3机械臂和Hermes底盘的联合控制系统，实现了两个机器人设备的协同作业。

### 🎯 设计目标
- **统一控制**：一个程序同时控制机械臂和底盘
- **序列编程**：支持复杂的多设备协同动作序列
- **精确控制**：保持各自设备的最佳控制精度
- **易于配置**：用户可自定义点位和运动序列

### 🏗️ 系统架构
```
┌─────────────────────────────────────────┐
│         联合控制器主程序                  │
│    CombinedRobotController              │
├─────────────────┬───────────────────────┤
│   机械臂控制     │      底盘控制          │
│   FR3 SDK       │    Hermes API         │
│ 192.168.58.2    │  192.168.31.211:1448  │
└─────────────────┴───────────────────────┘
```

## 配置说明

### 🦾 机械臂点位配置

在 `USER_ARM_POINTS` 中定义机械臂目标点位：

```python
USER_ARM_POINTS = {
    "point1": {
        "type": "joint",                    # 运动类型
        "position": [-54.14, -17.54, ...], # 关节角度 [J1-J6]
        "method": "MoveJ",                  # 运动方法
        "speed": 80.0,                      # 运动速度
        "wait_time": 0,                     # 停留时间(秒)
        "description": "工作台上方位置"       # 描述
    }
}
```

#### 运动类型说明
- **`"joint"`**: 关节空间运动，路径弯曲，适合大范围移动
- **`"linear"`**: 直线运动，TCP严格沿直线移动，高精度
- **`"cartesian"`**: 笛卡尔点到点运动

#### 速度参数
- **MoveJ**: 1-200，建议30-100
- **ServoCart**: 0-100，实际限制5-15（安全范围）

### 🚗 联合运动序列配置

在 `USER_MOTION_SEQUENCE` 中定义完整的协同动作序列：

```python
USER_MOTION_SEQUENCE = [
    "arm:point1",           # 机械臂移动到point1
    "chassis:1",            # 底盘导航到POI "1"
    {"wait": 5000},         # 等待5秒
    "arm:point5",           # 机械臂移动到point5
    "chassis:home1",        # 底盘导航到home1
]
```

#### 序列命令格式
1. **机械臂动作**: `"arm:点位名"`
2. **底盘动作**: `"chassis:POI名"`
3. **等待命令**: `{"wait": 毫秒数}`

```
Base URL: http://192.168.31.211:1448
API Endpoint: /api/core/motion/v1/actions
Method: POST
```

### 🎯 MultiFloorMoveAction核心实现

```python
payload = {
    "action_name": "slamtec.agent.actions.MultiFloorMoveAction",
    "options": {
        "target": {
            "poi_name": poi_name  # POI名称或ID
        },
        "move_options": {
            "mode": 0,                      # 自由导航模式
            "flags": ["with_yaw"],          # 精确到角标志
```

2. **获取任务ID**

### 🎯 精度计算

底盘导航完成后，系统会自动计算和显示精度：

```python
# 获取实际位置
current_pose = await self.get_current_chassis_pose()

# 计算位置误差
dx = target_x - actual_x
dy = target_y - actual_y
position_error = math.sqrt(dx*dx + dy*dy)

# 计算角度误差 (处理角度跳跃)
angle_diff = target_yaw - actual_yaw
if angle_diff > math.pi:
    angle_diff -= 2 * math.pi
elif angle_diff < -math.pi:
    angle_diff += 2 * math.pi
angle_error = abs(angle_diff)
```

### 📊 精度评级系统

- **位置精度**
  - 🟢 优秀: ≤5cm
  - 🟡 良好: ≤10cm
  - 🔴 一般: >10cm

- **角度精度**
  - 🟢 优秀: ≤3°
  - 🟡 良好: ≤10°
  - 🔴 一般: >10°

```python
def move_arm_to_point_joint(self, point_name, target_joints, velocity=30.0):
    # 带参数的MoveJ调用
    ret = self.robot.MoveJ(
        joint_pos=target_joints,        # 目标关节角度
```

### 📏 直线运动实现 (ServoCart)

直线运动使用伺服模式实现高精度轨迹跟随：

```python
def move_arm_to_point_linear(self, point_name, target_position, velocity=30.0):
    # 1. 获取起始位置
    start_pos = self.get_current_tcp_pose()
    
    # 2. 生成直线轨迹 (200个插值点)
    trajectory = self.generate_linear_trajectory(start_pos, target_position, 200)
    
    # 3. 启动伺服模式
    ret = self.robot.ServoMoveStart()
    
    # 4. 轨迹跟随
    for pos in trajectory:
        ret = self.robot.ServoCart(mode=0, desc_pos=pos, vel=safe_velocity)
        time.sleep(0.008)  # 8ms伺服周期
    
    # 5. 结束伺服模式
    ret = self.robot.ServoMoveEnd()
```

### 📐 三次S曲线轨迹生成

为确保运动平滑，使用三次S曲线进行轨迹插值：

```python
def generate_linear_trajectory(self, start_pos, end_pos, steps):
    trajectory = []
    for i in range(steps + 1):
        t_linear = i / steps
        
        # 三次S曲线函数: 3t² - 2t³
        t = 3 * t_linear * t_linear - 2 * t_linear * t_linear * t_linear
        
        # 插值计算
        interpolated_pos = []
        for j in range(len(start_pos)):
            interpolated_value = start_pos[j] + t * (end_pos[j] - start_pos[j])
            interpolated_pos.append(interpolated_value)
        
        trajectory.append(interpolated_pos)
    
    return trajectory
```

## 联合控制原理

### 🔄 控制流程

```
用户序列 → 序列解析 → 设备调度 → 动作执行 → 状态监控 → 结果统计
    ↓
序列验证 ← 点位检查 ← 设备连接 ← 初始化
```

### 🎛️ 设备调度逻辑

```python
async def execute_sequence(self):
    for step in self.motion_sequence:
        if isinstance(step, str):
            if step.startswith("arm:"):
                # 同步调用机械臂
                point_name = step[4:]
                success = self.move_arm_to_point(point_name)
                
            elif step.startswith("chassis:"):
                # 异步调用底盘
                poi_name = step[8:]
                success = await self.navigate_chassis_to_poi(poi_name)
                
        elif isinstance(step, dict) and 'wait' in step:
            # 异步等待
            await self.wait_with_countdown(step['wait'])
```

### 🔗 同步/异步混合设计

- **机械臂控制**: 同步调用 (blocking)
- **底盘控制**: 异步调用 (async/await)
- **等待命令**: 异步等待 (async/await)

这种设计确保了：
1. 机械臂动作的精确控制
2. 底盘导航的非阻塞监控
3. 整体序列的流畅执行
