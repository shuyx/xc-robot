# 乐白夹爪完整部署指南

## 📋 概述
本指南提供通过FR3机械臂末端自定义协议控制乐白夹爪的完整解决方案。

## ⚠️ 前提条件

### 硬件要求
- FR3机械臂（法奥意威）
- 乐白夹爪（LMG-90或LMG-40）
- M8-8P转M12-5芯连接线

### 软件要求
- **FR3软件版本**: V3.7.4 或更高
- **末端固件版本**: FR_END_FV201005_MAIN_U01_T01_20240806.bin 或更高

### 接线确认
```
乐白夹爪M8-8P → FR3末端M12-5芯
1号线(棕) → 24V供电
2号线(绿) → 地线  
5号线(橙) → 485A
6号线(蓝) → 485B
```

## 🚀 部署步骤

### 方法一：自动部署（推荐）

1. **运行自动部署脚本**
   ```bash
   cd testing3
   python lebai_gripper_complete_deployment.py
   ```

2. **脚本会自动完成**：
   - 连接机械臂
   - 上传乐白夹爪Lua协议文件
   - 配置末端通讯参数 (115200, 8N1)
   - 启用末端Lua执行
   - 配置夹爪设备类型和功能
   - 初始化和测试夹爪

### 方法二：手动配置

#### 步骤1: 固件升级
1. 进入FR3 WebApp → 辅助应用 → 机器人本体 → 系统升级
2. 软件升级到V3.7.4
3. 固件升级到最新版本

#### 步骤2: 上传Lua协议文件
1. 使用文件升级工具 `filetrsf.exe`
2. 处理 `AXLE_LUA_LEBAI_GRIPPER.lua` 文件
3. 进入WebApp → 初始设置 → 末端工具 → 开放协议
4. 上传处理后的Lua文件

#### 步骤3: 配置末端参数
1. 进入Boot模式
2. 设置通讯参数：
   - 波特率：115200
   - 数据位：8
   - 停止位：1
   - 校验：无
   - 超时：5000ms

#### 步骤4: 启用功能
1. 勾选以下功能：
   - ✅ 初始化
   - ✅ 位置控制
   - ✅ 速度控制
   - ✅ 力矩控制
   - ✅ 读取状态

## 🔧 故障排除

### 常见问题及解决方案

#### 问题1: MoveGripper返回错误码73
**原因**: 标准MoveGripper指令与乐白夹爪不兼容
**解决**: 使用本指南提供的末端自定义协议

#### 问题2: 连接失败或通讯超时
**检查项**:
- ✅ 485接线是否正确
- ✅ 夹爪供电是否正常(24V)
- ✅ 通讯参数是否匹配
- ✅ 夹爪设备地址是否为1

#### 问题3: Lua文件上传失败
**检查项**:
- ✅ 是否进入Boot模式
- ✅ 文件名是否以AXLE_LUA_开头
- ✅ 文件格式是否正确

#### 问题4: 夹爪无响应
**排查步骤**:
1. 检查ActGripper是否成功激活
2. 验证末端Lua执行是否启用
3. 确认夹爪功能配置是否正确
4. 测试手动发送Modbus指令
