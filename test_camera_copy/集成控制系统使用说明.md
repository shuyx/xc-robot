# 水杯检测+机械臂控制集成系统使用说明

## 🎯 系统概述

该集成系统结合了深度相机检测和FR3机械臂控制，实现：
1. 自动检测水杯距离
2. 计算机械臂前伸距离（检测距离 - 10cm）
3. 控制机械臂自动前伸到目标位置

## 📋 核心功能

### 🔍 水杯检测模块
- 使用深度分析算法检测最近物体（水杯）
- 精确计算3D坐标和距离
- 实时反馈检测结果

### 🤖 机械臂控制模块
- 严格按照您的控制格式实现
- 使用ServoCart进行平滑直线运动
- Z轴负方向前伸控制
- 轨迹插值和安全检查

### 📏 手眼转换
- **转换公式**: 机械臂移动距离 = 检测距离 - 100mm
- **安全范围**: 50mm - 800mm
- **自动校验**: 防止过近或过远操作

## ⚙️ 技术参数

### 检测精度
- **距离精度**: ±5mm (理想条件)
- **检测范围**: 200mm - 3000mm
- **响应时间**: <2秒

### 机械臂控制
- **移动精度**: ±5mm
- **移动速度**: 10mm/s (平滑运动)
- **安全范围**: 50mm - 800mm
- **轨迹类型**: S曲线插值平滑运动

### 手眼标定
- **固定偏移**: 100mm (10cm)
- **坐标系**: 相机Z轴 → 机械臂Z轴负方向
- **转换公式**: robot_distance = camera_distance - 100mm

## 🛡️ 安全机制

### 自动安全检查
1. **距离合理性**: 检测距离在20cm-3m范围内
2. **移动范围**: 机械臂移动距离5cm-80cm
3. **操作确认**: 每次移动前需要用户确认
4. **轨迹平滑**: 使用S曲线避免急停急起
5. **错误处理**: 完整的异常捕获和资源清理

### 故障安全模式
- 相机初始化失败 → 程序终止
- 机械臂连接失败 → 仅检测模式
- 检测失败 → 不执行机械臂控制
- 距离超出范围 → 安全停止

## 🔧 故障排除

### 问题1: 相机初始化失败
```
❌ 无法获取深度传感器
```
**解决方案**:
1. 检查相机USB连接
2. 确保在test_camera_copy目录运行
3. 关闭其他占用相机的程序

### 问题2: 机械臂连接失败
```
❌ 机械臂连接失败
```
**解决方案**:
1. 检查网络连接 (192.168.58.2)
2. 确保机械臂电源开启
3. 检查fr3_control路径是否正确

### 问题3: 检测不到水杯
```
❌ 未检测到水杯
```
**解决方案**:
1. 确保水杯是最近物体
2. 改善光照条件
3. 使用深色背景
4. 检查水杯是否在检测范围内

### 问题4: 移动距离超出范围
```
⚠️ 移动距离太大，超出安全范围
```
**解决方案**:
1. 将水杯放置在合适距离 (30-90cm)
2. 检查相机对准是否正确
3. 确认检测到的是水杯而不是背景

## 📈 性能优化建议

### 提高检测成功率
1. **最佳距离**: 相机距离水杯60-80cm
2. **背景设置**: 使用深色单一背景
3. **光照条件**: 避免强光直射，保持均匀照明
4. **物体清理**: 移除前景中的其他物体

### 提高控制精度
1. **系统预热**: 让机械臂运行几分钟预热
2. **环境稳定**: 避免振动和温度变化
3. **定期标定**: 根据需要调整手眼偏移参数
