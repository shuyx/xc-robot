# 水杯检测脚本使用说明

**特点**：

## 📊 检测原理

### 核心算法：深度分析法
```python
# 基本流程
1. 获取深度图像
2. 过滤有效深度范围 (20cm-3m)
3. 找到最近的深度值
4. 找该深度附近的像素区域 (±2cm容差)
5. 检查物体大小合理性
6. 计算物体中心位置
7. 转换为3D坐标
```

### 坐标系说明
```
相机坐标系:
- X轴: 指向相机右侧 (+右, -左)
- Y轴: 指向相机下方 (+下, -上)  
- Z轴: 指向相机前方 (+前, -后)
- 原点: 相机光心位置
```

## 🎯 使用建议

### 最佳拍摄设置
1. **距离**：相机距离水杯60-80cm
2. **角度**：从前往后拍摄
3. **背景**：使用深色背景布（深蓝或深绿）
4. **环境**：避免强光直射，保持均匀光照
5. **物体**：确保水杯是离相机最近的物体

### 提高检测成功率的技巧
1. **清空前景**：移除相机和水杯之间的其他物体
2. **稳定放置**：水杯放置稳定，避免晃动
3. **背景简化**：使用单一颜色的背景
4. **多次测试**：连续检测取平均值

## 📈 性能指标

### 增强版脚本预期性能
- **检测成功率**: >90% (理想条件下)
- **定位精度**: ±0.5cm (距离80cm时)
- **处理速度**: ~2fps
- **有效检测距离**: 20cm - 2m

### 优化功能
- **多帧平均**: 最近5次结果平均，减少抖动
- **深度降噪**: 3帧中位数滤波
- **自适应容差**: 根据距离调整深度容差
- **加权中心**: 使用深度加权计算更准确的中心

### 常见失败原因
1. **"物体太小"** - 水杯离得太远或被遮挡
2. **"物体太大"** - 背景被识别为最近物体
3. **"距离不合理"** - 检测到的不是水杯
4. **"深度数据太少"** - 光照不足或反射问题

## 🛠️ 故障排除

### 问题1：相机初始化失败
```bash
❌ 无法获取深度传感器
```
**解决方案**：
1. 检查相机连接
2. 确保在test_camera_copy目录运行
3. 检查其他程序是否占用相机

### 问题2：导入错误
```bash
ImportError: cannot import name 'OBSensorType'
```
**解决方案**：
1. 退出虚拟环境：`deactivate`
2. 在test_camera_copy目录运行
3. 使用系统Python而不是虚拟环境

### 问题3：检测不稳定
**解决方案**：
1. 改善光照条件
2. 使用深色背景
3. 确保水杯是最近物体
4. 使用增强版脚本的多帧平均功能

```python

self.depth_tolerance = 20  # 深度容差 (mm)
self.min_pixels = 50       # 最小像素数
self.max_pixels = 50000    # 最大像素数
```
