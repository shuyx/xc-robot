# 相机3D定位方案说明

## 🎯 目标
通过安装在机械臂上的Orbbec Gemini 335深度相机，获取桌面纸杯的3D坐标，为机械臂抓取提供位姿信息。

---

## 📊 技术方案

### 整体流程
```
彩色图像 + 深度图像 
    ↓
物体检测 (找到纸杯在图像中的位置)
    ↓  
深度获取 (获取该位置的深度值)
    ↓
坐标转换 (像素坐标 + 深度 → 3D坐标)
    ↓
机械臂坐标系转换
```

### 核心算法

#### 1. 像素坐标到3D坐标转换
```python
# 相机内参
fx, fy = 焦距
cx, cy = 主点坐标

# 坐标转换公式
z = depth_value / 1000.0  # 深度值转米
x = (pixel_x - cx) * z / fx
y = (pixel_y - cy) * z / fy

# 结果: (x, y, z) 相机坐标系下的3D坐标
```

#### 2. 相机坐标系定义
- **X轴**: 指向相机右侧
- **Y轴**: 指向相机下方  
- **Z轴**: 指向相机前方
- **原点**: 相机光心

## 🔧 实现方案

### 方案A: 传统视觉检测 (推荐开始)
**优点**: 
- 简单可靠
- 实时性好
- 易于调试

**检测方法**:
```python
# 颜色分割 (白色纸杯)
hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, lower_white, upper_white)

# 轮廓检测
contours = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
largest_contour = max(contours, key=cv2.contourArea)

# 中心点计算
M = cv2.moments(largest_contour)
cx = int(M["m10"] / M["m00"])
cy = int(M["m01"] / M["m00"])
```

### 方案B: 深度数据分析
**适用场景**: 彩色传感器不可用或光线条件差

**检测方法**:
```python
# 找到最近的物体点
valid_depth = depth_image[(depth_image > 200) & (depth_image < 2000)]
min_depth = np.min(valid_depth)
positions = np.where(depth_image == min_depth)
```

## 🔄 坐标系转换 (未来扩展)

### 相机坐标系 → 机械臂坐标系
需要标定相机与机械臂的相对位置关系:

```python
# 标定矩阵 (需要实际标定获得)
R = np.array([[...], [...], [...]])  # 旋转矩阵 3x3
t = np.array([x, y, z])              # 平移向量

# 坐标转换
robot_pos = R @ camera_pos + t
```

**标定方法**:
1. 手眼标定 (Eye-in-Hand)
2. 使用标定板或已知点位
3. 多点对应关系求解

## ⚠️ 注意事项

### 环境要求
- 充足的光线 (彩色检测)
- 避免强反光表面
- 桌面与纸杯有足够对比度

### 深度相机限制
- 有效距离: 0.3m - 10m
- 精度: ±1% (在1m距离)
- 受环境光影响较小

### 检测鲁棒性
- 处理遮挡情况
- 多个物体的区分
- 不同角度的识别
