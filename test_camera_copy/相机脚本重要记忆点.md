### 关键API修正点
```python
# ❌ 错误的内参获取方式

# ✅ 正确的内参获取方式  
depth_video_profile = depth_profile.as_video_stream_profile()

# 内参使用
fx, fy = intrinsics.fx, intrinsics.fy  # 焦距
cx, cy = intrinsics.ppx, intrinsics.ppy  # 主点
```

### 深度数据处理标准流程
```python
# 1. 获取深度帧
depth_frame = frames.get_depth_frame()

# 2. 转换为numpy数组
depth_data = np.frombuffer(depth_frame.get_data(), dtype=np.uint16)
height = depth_frame.get_height()
width = depth_frame.get_width()
depth_image = depth_data.reshape((height, width))

# 3. 像素坐标转3D坐标
z = depth_value / 1000.0  # 毫米转米
x = (pixel_x - cx) * z / fx
y = (pixel_y - cy) * z / fy
```

### 拍摄角度选择
**最终推荐**: 从前往后拍摄 + 背景布

## 🎯 核心算法 - 深度分析检测

### 检测流程
```python
def analyze_depth_for_cup(depth_image, intrinsics):
    # 1. 过滤有效深度 (20cm-3m)
    valid_depth = depth_image[(depth_image > 200) & (depth_image < 3000)]
    
    # 2. 找最近物体
    closest_depth = np.min(valid_depth)
    
    # 3. 找相近深度的像素区域
    tolerance = 20  # 2cm容差
    cup_mask = np.abs(depth_image - closest_depth) <= tolerance
    
    # 4. 检查物体大小合理性
    cup_pixels = np.sum(cup_mask)
    if 50 < cup_pixels < 50000:  # 合理尺寸
        
        # 5. 计算物体中心
        positions = np.where(cup_mask)
        center_x = int(np.mean(positions[1]))
        center_y = int(np.mean(positions[0]))
        
        # 6. 转换3D坐标
        z = closest_depth / 1000.0
        x = (center_x - intrinsics.ppx) * z / intrinsics.fx  
        y = (center_y - intrinsics.ppy) * z / intrinsics.fy
        
        return (center_x, center_y, closest_depth, x, y, z)
```

### 坐标系说明
```
相机坐标系:
- X轴: 指向相机右侧 (+右, -左)
- Y轴: 指向相机下方 (+下, -上)  
- Z轴: 指向相机前方 (+前, -后)
- 原点: 相机光心位置
```

## 🎯 深度检测算法优化 (2025-08-02 新增)

### 区域限制技术
**问题**: 原深度检测会误检到桌面边缘作为最近点  
**解决方案**: 添加Y坐标区域限制，只检测画面上75%区域

```python
# 关键改进
height, width = depth_image.shape
y_detection_ratio = 0.75  # 只检测上75%区域，避免桌面
y_limit_pixel = int(height * y_detection_ratio)

# 创建区域掩码
detection_mask = np.zeros_like(depth_image, dtype=bool)
detection_mask[:y_limit_pixel, :] = True  # 只在上75%区域检测

# 在限制区域内找最近物体
valid_mask = (depth_image > 200) & (depth_image < 3000) & detection_mask
closest_depth = np.min(depth_image[valid_mask])
```

**效果**: 有效避免桌面干扰，提高水杯检测准确率

### 检测策略简化
**发现**: 物体大小检查会导致检测失败  
**改进**: 移除像素数量限制，直接检测最近点
```python
# 简化后的核心逻辑
closest_positions = np.where((depth_image == closest_depth) & detection_mask)
center_y = closest_positions[0][0]
center_x = closest_positions[1][0]
```
