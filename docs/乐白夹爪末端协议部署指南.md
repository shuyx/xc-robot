# 乐白夹爪末端协议部署指南

## 概述

本指南详细介绍如何在FR3机器人控制器上部署和使用乐白夹爪的Lua末端通讯协议文件，实现夹爪的完整控制功能。

## 文件信息

- **协议文件**: `AXLE_LUA_End_LeBai.lua`
- **协议类型**: Modbus RTU
- **通讯参数**: 115200bps, 8N1
- **设备地址**: 1-8 (可配置)
- **支持功能**: 激活、复位、位置控制、速度控制、力矩控制、状态查询

## 部署前准备

### 1. 系统要求
- FR3机器人控制器
- 软件版本: 3.7.4及以上
- 末端固件: 支持开放协议版本
- 乐白夹爪LMG-90系列

### 2. 硬件连接
- **电源**: 24V DC接入机器人末端电源
- **通讯**: RS485接入机器人末端通讯接口
- **接线参考**: 按照乐白夹爪接线说明完成连接

### 3. 通讯参数配置
```
波特率: 115200
数据位: 8
停止位: 1
校验位: None
设备地址: 1-8 (推荐使用1)
```

## 部署步骤

### 步骤1: 文件格式转换
1. 使用FR3提供的 `filetrsf.exe` 工具转换文件格式
2. 将 `AXLE_LUA_End_LeBai.lua` 转换为机器人可识别的格式

### 步骤2: 机器人进入Boot模式
1. 关闭机器人电源
2. 按住急停按钮
3. 开启机器人电源
4. 等待进入Boot模式

### 步骤3: 上传协议文件
1. 通过网络连接到机器人控制器
2. 使用Web界面或专用工具上传转换后的协议文件
3. 确认文件上传成功

### 步骤4: 重启机器人
1. 重启机器人控制器
2. 等待系统完全启动
3. 检查末端协议是否加载成功

## Web界面配置

### 1. 末端工具配置
1. 进入机器人Web示教界面
2. 选择"末端工具"配置
3. 选择"自定义夹爪"类型
4. 勾选以下功能:
   - ☑️ 夹爪激活
   - ☑️ 夹爪复位  
   - ☑️ 位置控制
   - ☑️ 速度控制
   - ☑️ 力矩控制
   - ☑️ 状态查询

### 2. 通讯参数设置
```
设备地址: 1 (或实际使用的地址)
通讯协议: 末端Lua协议
协议文件: AXLE_LUA_End_LeBai
```

## 故障排除

### 常见问题

#### 1. 协议文件加载失败
**现象**: Web界面显示"末端Lua文件异常"  
**解决方案**:
- 检查文件格式是否正确转换
- 确认文件名以"AXLE_LUA_"开头
- 重新上传协议文件

#### 2. 夹爪无响应
**现象**: 发送控制命令但夹爪不动作  
**解决方案**:
- 检查硬件连接（电源、通讯线）
- 确认设备地址配置正确
- 验证通讯参数设置

#### 3. 状态读取失败
**现象**: 无法获取夹爪状态信息  
**解决方案**:
- 检查夹爪是否正确激活
- 确认寄存器地址映射正确
- 增加通讯延时时间

#### 4. CRC校验错误
**现象**: 通讯出现校验错误  
**解决方案**:
- 确认CRC计算算法正确
- 检查数据传输完整性
- 排查通讯干扰问题

### 调试方法

#### 1. 通讯监控
使用示波器或逻辑分析仪监控RS485通讯数据，确认：
- 波特率设置正确
- 数据帧格式正确
- CRC校验值正确

#### 2. 日志分析
查看机器人控制器日志，关注：
- 末端协议加载信息
- 通讯错误记录
- 夹爪响应状态

#### 3. 分步测试
按照以下顺序逐步测试：
1. 协议文件加载
2. 夹爪激活
3. 基础位置控制
4. 状态读取功能
5. 完整功能测试
