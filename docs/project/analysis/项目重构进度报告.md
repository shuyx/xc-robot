## 项目背景

基于用户需求重新设计项目架构，实现前后端完全解耦的测试页面服务，支持未来Web测试界面的独立开发和部署。

## 新架构设计

### 5层分层架构
```
应用层 (Apps) ← API网关层 (Gateway) ← 服务层 (Services) ← 核心层 (Core) ← 硬件层 (Hardware)
```

### 解耦原则
- 前后端完全分离
- 每层职责单一，可独立开发测试  
- 通过标准化API接口通信
- 支持多种前端应用（桌面、Web、移动）

## 核心技术特性

### Web测试页面架构

**前端技术栈** (渐进式方案):
- Phase 1: HTML + CSS + Vanilla JS + WebSocket (快速原型) ✅
- Phase 2: React/Vue + TypeScript + WebSocket (生产级) (规划中)

**API设计**:
```yaml
# 机器人控制API
GET    /api/v1/robots/status          # 获取所有机器人状态
POST   /api/v1/robots/connect         # 连接机器人
POST   /api/v1/robots/disconnect      # 断开连接
POST   /api/v1/robots/emergency-stop  # 紧急停止

# 任务管理API  
POST   /api/v1/tasks/execute          # 执行任务
GET    /api/v1/tasks/{id}/status      # 获取任务状态
DELETE /api/v1/tasks/{id}             # 取消任务

# 实时通信
WebSocket /ws/robot-status            # 机器人状态推送
WebSocket /ws/task-logs               # 任务日志推送
```

## 架构优势

### 1. 完全解耦
- 前端通过标准HTTP/WebSocket与后端交互
- 各层可以独立开发、测试和部署

### 2. 独立开发
- 前后端可以并行开发，接口约定清晰
- 支持多种前端技术栈

### 3. 易于测试
- 每层都可以独立单元测试
- 分层架构便于集成测试

### 4. 扩展性强
- 容易添加新的前端应用或后端服务
- 模块化设计支持功能扩展

### 5. 部署灵活
- 可以独立部署API服务和前端应用
- 支持容器化和微服务架构
