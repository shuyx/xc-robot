# FR3机械臂与乐白夹爪配置指南

## 概述

本指南基于官方文档资料，详细说明如何配置FR3机械臂与乐白夹爪的通讯连接，并实现基本的开合控制功能。

## 硬件规格

### 乐白夹爪技术参数
- **通讯协议**: RS485 Modbus RTU
- **供电要求**: 24V DC
- **波特率**: 115200
- **数据格式**: 8N1 (8数据位，无校验，1停止位)
- **设备地址**: 01 (默认)
- **行程范围**: 0-90mm (寸夹爪) / 20-60mm (LMG-40)
- **夹持力**: 10-35N (寸夹爪) / 12-50N (LMG-40)

### FR3机械臂接口
- **末端接口**: M12-5芯485接口
- **支持协议**: Modbus (协议号4098)
- **通讯参数**: 可配置波特率、数据位等

## 接线说明

### 乐白夹爪接线定义 (M8-8P母弯头)
| 针脚 | 颜色 | 功能定义 |
|------|------|----------|
| 1    | 棕   | 24V     |
| 2    | 绿   | 地(GND) |
| 3    | 黄   | 输出1   |
| 4    | 黑   | 输出2   |
| 5    | 橙   | 485A    |
| 6    | 蓝   | 485B    |
| 7    | 白   | 输入1   |
| 8    | 红   | 输入2   |

### 连接到FR3末端法兰
- 橙色线(485A) → FR3末端485A
- 蓝色线(485B) → FR3末端485B  
- 棕色线(24V) → 外部24V电源正极
- 绿色线(GND) → 外部24V电源负极

## Modbus寄存器地址

| 寄存器地址 | 十六进制 | 功能说明 | 数据范围 | 读写权限 |
|------------|----------|----------|----------|----------|
| 40000 | 0x9C40 | 夹爪幅度控制 | 0-100% | 可写 |
| 40001 | 0x9C41 | 夹爪力度控制 | 0-100% | 可写 |
| 40005 | 0x9C45 | 夹爪当前位置 | 0-100% | 只读 |
| 40006 | 0x9C46 | 夹爪当前力矩 | 0-100% | 只读 |
| 40072 | 0x9C48 | 手动找行程 | 0/1 | 可写 |
| 40154 | 0x9C9A | 关闭自动找行程 | 0/1 | 可写 |

## 配置步骤

### 1. 硬件连接检查
- [ ] 确认夹爪24V电源正常供电
- [ ] 检查485通讯线连接正确
- [ ] 验证夹爪机械安装牢固
- [ ] 确保夹爪活动范围无障碍

### 2. FR3机械臂软件配置

#### 方法一：使用Python SDK
```python
from fairino import Robot

# 连接机械臂
robot = Robot.RPC("192.168.58.2")

# 设置外设协议为Modbus
error = robot.SetExDevProtocol(4098)  # 4098 = Modbus协议

# 配置通讯参数 (波特率, 数据位, 停止位, 校验位, 超时, 重试次数, 周期)
error = robot.SetAxleCommunicationParam(115200, 8, 1, 0, 3000, 3, 1000)
```

#### 方法二：使用WebApp界面
1. 登录FR3 WebApp控制界面
2. 进入"末端外设配置"页面
3. 设备类型选择"夹爪设备"
4. 配置厂商、型号、版本信息
5. 设置挂载位置
6. 点击"配置"按钮

### 3. 夹爪初始化
按以下顺序执行：
1. **复位夹爪**: 先点击"复位"按钮
2. **激活夹爪**: 再点击"激活"按钮
3. **找行程**: 发送找行程指令（可选，夹爪上电5秒后自动执行）

### 4. 基本控制指令

#### 标准控制指令
```python
# 夹爪打开 (位置0%, 速度50%, 力度30%)
robot.MoveGripper(1, 0, 50, 30, 5000, 0, 0, 0, 0, 0)

# 夹爪闭合 (位置100%, 速度50%, 力度50%)  
robot.MoveGripper(1, 100, 50, 50, 5000, 0, 0, 0, 0, 0)
```

#### 参数说明
- `index`: 夹爪编号 (通常为1)
- `pos`: 目标位置百分比 (0-100)
- `vel`: 速度百分比 (0-100)
- `force`: 力度百分比 (0-100)
- `maxtime`: 最大执行时间 (毫秒)
- `block`: 是否阻塞 (0-阻塞, 1-非阻塞)
- `type`: 夹爪类型 (通常为0)
- `rotNum`: 旋转圈数 (通常为0)
- `rotVel`: 旋转速度 (通常为0)
- `rotTorque`: 旋转扭矩 (通常为0)

#### Modbus直接控制示例
```python
# Modbus RTU指令格式参考
# 设置夹爪位置到100% (完全闭合)
# 01 10 9C 40 00 01 02 00 64 FS 72

# 设置夹爪力度到50%
# 01 10 9C 41 00 01 02 00 32 74 9D

# 执行找行程
# 01 10 9C 48 00 01 02 00 01 34 11
```

## 故障排除

### 常见问题

#### 1. 夹爪无响应
**可能原因**:
- 24V电源供电异常
- 485通讯线接错或接触不良
- 设备地址不匹配
- 通讯参数配置错误

**解决方案**:
- 检查电源指示灯状态
- 验证接线是否按照针脚定义连接
- 确认设备地址为01
- 重新配置通讯参数(115200, 8N1)

#### 2. 连接机械臂失败
**可能原因**:
- 网络连接问题
- IP地址错误
- 机械臂控制器未启动

**解决方案**:
- 检查网络连接状态
- 验证机械臂IP地址
- 重启机械臂控制器

#### 3. 外设协议设置失败
**可能原因**:
- 机械臂固件版本不支持
- 有其他程序占用外设接口
- 权限不足

**解决方案**:
- 联系技术支持升级固件
- 关闭其他控制程序
- 重启控制器

#### 4. 夹爪动作异常
**可能原因**:
- 力度设置过大或过小
- 机械结构卡顿
- 未执行找行程

**解决方案**:
- 调整力度参数(建议30-50%)
- 检查机械安装和活动空间
- 重新执行找行程操作

## 注意事项

### 安全提醒
- ⚠️ 首次使用前必须执行找行程操作
- ⚠️ 调试时将机械臂速度调至较低值
- ⚠️ 确保夹爪活动范围内无人员和障碍物
- ⚠️ 异常情况下立即按下急停按钮

### 操作建议
- 建议使用30-50%的力度进行日常操作
- 定期检查机械连接紧固状态
- 注意夹爪的负载限制(3kg)
- 避免频繁大力度操作以延长使用寿命

### 兼容性说明
- 适用于FR3系列协作机械臂
- 支持乐白寸夹爪和LMG-40夹爪
- 需要WebApp版本3.8.2或更高版本
- 建议使用Python SDK v2.0.5或更高版本
